### What are you most proud of, and what would you do differently next time?

On this occasion, I was able to configure my responsive design clearly. After reading feedback about web design, I was able to achieve a more responsive design. Next time, I want to manipulate the DOM to create better interaction.

### What challenges did you encounter, and how did you overcome them?

Working with the form was a challenge when I started. I wanted to create a form that achieved the objective of the project. So, I decided to dedicate time to reading the documentation and practicing. Later, I read about implementing validation. This project was a great challenge.

### What specific areas of your project would you like help with?

On this occasion, I have questions about the `<form>` element.

In the documentation, it says that this element is used to contain and organize other elements related to a form. So, I thought that I could use it to contain all the elements inside the first card.

For instance, I could do this:

```html
<form>
  <picture>
  </picture>

  <div>
    <h1></h1>
    <p></p>

    <ul>
      <li></li>
      <li></li>
      <li></li>
    </ul>

    <div>
      <div>
        <label></label>
        <span></span>
      </div>

      <input />
      <button></button>
    </div>
  </div>
</form>
```

So, I think it would be interesting to discuss whether using the `<form>` element in this way is appropriate.
